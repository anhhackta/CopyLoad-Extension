Làm được gì

Bản 1.0.2 viết lại kiến trúc: IndexedDB, ảnh, Paste Multi, khóa PIN — vẫn 100% local.

Text + ảnh

Tự lưu khi copy; chuột phải lưu text/ảnh; phân loại link, email, số, code.

Paste Multi

Ctrl+V trong ô nhập để chọn đoạn đã lưu — hộp gợi ý hoặc phím 1–0.

PIN & quyền riêng tư

Khóa giao diện bằng PIN 4–6 số. Không analytics, không gửi clipboard đi đâu.

Xuất / nhập

Backup JSON (có thể mã hóa mật khẩu), tải .txt, tự xóa mục cũ, ghim mục quan trọng.

Cài đặt từ ZIP

Chưa lên Store — tải từ Releases rồi nạp unpacked.

  1. Tải ZIP bản Latest trên GitHub Releases.
  2. Giải nén ra một thư mục (giữ nguyên cấu trúc).
  3. Mở chrome://extensions hoặc edge://extensions, bật Developer mode.
  4. Load unpacked → chọn thư mục có manifest.json.
