Built for everyday clipboard work

v1.0.2 is a full rebuild: IndexedDB history, images, Paste Multi, and PIN — still 100% local.

Text + images

Auto-save on copy, right-click capture, image paste from the system clipboard, thumbnails, and search.

Smart classification

Entries are tagged as text, link, email, number, or code. Pin important items so cleanup never removes them.

Paste Multi

Press Ctrl+V in an input to pick a saved snippet — suggestion box or quick keys 1–0. Ctrl+Shift+V stays a normal paste.

Temp vs permanent

Turn off “Save permanently” for session-only text. Images follow the same switch so nothing leaks into long-term storage by accident.

PIN lock

Optional 4–6 digit PIN for the popup, manager, and Paste Multi, with lock timeout and attempt limits.

Backup & cleanup

Export/import JSON (optional password encryption), plain .txt export, auto-delete old items, and bulk delete.

How it works

A small Manifest V3 extension: content script listens, service worker writes, IndexedDB stores, UI reads.

Capture flow

  1. You copy, cut, or paste text on a page (or right-click save).
  2. The content script sends a typed message to the background worker.
  3. History is written to IndexedDB; temporary text uses session storage.
  4. Popup / manager refresh the list with search, pins, and paging.

Paste Multi

  • Box mode: Ctrl+V opens a floating picker (↑↓, Enter, 1–0).
  • Quick mode: Ctrl+V then press a digit within the short window.
  • Bypass with Ctrl+Shift+V or the page’s own Paste menu.
  • When PIN lock is “every open”, Paste Multi stays locked until unlock.

Install from ZIP

Not on the Chrome Web Store yet. Use Developer mode → Load unpacked.

  1. Download the Latest ZIP from GitHub Releases.
  2. Unzip into a folder and keep the file structure intact.
  3. Open chrome://extensions or edge://extensions and enable Developer mode.
  4. Load unpacked → select the folder that contains manifest.json.

Privacy by design

Clipboard content never leaves the machine for analytics or remote sync.

Local storage only

History lives in IndexedDB. Settings use chrome.storage.sync / local. No remote clipboard API.

PIN is a UI lock

PIN is hashed with PBKDF2. It protects opening the UI / Paste Multi — it does not encrypt the whole database at rest.

Encrypted exports

When you export with a password, the JSON backup is encrypted with AES-GCM. Lose the password and the file cannot be opened.

FAQ

Short answers to common install and usage questions.

Why isn’t CopyLoad on the Chrome Web Store?

The current distribution path is GitHub Releases + Load unpacked. Store publishing may come later; the ZIP path stays supported.

Does Paste Multi replace every Ctrl+V?

Only when Paste Multi is enabled and focus is in an editable field. Use Ctrl+Shift+V or the page Paste menu for a normal paste.

Is my clipboard uploaded anywhere?

No. History stays on the device. The landing page and docs may load fonts from Google Fonts; the extension itself does not send clipboard data to the network.

What happened to version 1.1.1?

It remains available as the first public release (tag Ver1.1.1, branch legacy-old). It is no longer marked Latest — use v1.0.2 for the current product.
